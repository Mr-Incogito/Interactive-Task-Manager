# Interactive Task Manager – Week 8

## Files
- `src/index.html` – page structure and task form
- `src/style.css` – layout, colours and responsive styling
- `src/script.js` – task functionality and localStorage persistence

## How to run
1. Extract the ZIP file.
2. Open the `src` folder.
3. Open `index.html` in a modern web browser.

## Features
- Add a task with a description and priority.
- Mark a task as complete and undo completion.
- Delete a task.
- Display the number of tasks and remaining tasks.
- Save tasks in browser localStorage using JSON.
- Restore saved tasks after refreshing the page.
- Responsive layout for smaller screens.
